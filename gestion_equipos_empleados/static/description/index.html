Equipment & Employee Management + AI Module (Odoo 18)

A complete and intelligent solution to manage IT assets, employee assignments, loan tracking, and AI-powered insights.

Key Functionalities

  • Manage all your equipment and assign them to employees
  • Generate PDF loan reports and send via email
  • Employee Digital Signature
  • Integrated with OpenAI to assist with hardware-related questions
  • User roles: Administrator vs Consultant with distinct permissions
  • QR Code auto-generated for each equipment item
  • Security configured via security.xml and ir.model.access.csv
  • Fully documented module (15-page PDF with install steps, code structure, AI integration, tests, QWeb, etc.)

Equipment Management

  • Track devices such as laptops, monitors, phones, tablets...
  • Store brand, model, supplier, purchase date, specs, and notes
  • QR Code per equipment for quick access and inventory
  • Assign equipment to employees and view change history

Employee Management

  • Fully integrated with hr.employee
  • Visual overview of equipment assigned to each employee
  • Extra fields to store roles and internal notes

🔁 Loan Management

  • Create loan records with delivery and return dates
  • Export PDF loan report
  • Send loan report via email with a single click
  • Status and overview of current loans per device/employee

AI Assistant with OpenAI

  • OpenAI integration using your API Key
  • Chat-style assistant to answer hardware or IT-related queries
  • Helps identify device issues based on logs or comments
  • Gives recommendations (e.g. repair, replacement)

Security & Roles

  • Admin users: full access to create/edit/delete equipment and loans
  • Consultant users: can only view assigned equipment and loans
  • Access rights defined in security.xml and ir.model.access.csv

Employee Digital Signature

  • Allows employees to digitally sign loan agreements
  • Signature is stored as an image and linked to the loan record
  • Visible in the loan form view and included in the PDF report
  • Improves legal compliance and asset accountability

Documentation

  • Complete 15-page PDF manual included in the module
  • Explains installation, models, AI setup, user roles and permissions
  • Shows QWeb loan reports and how to send them via email
  • Includes testing instructions for proper usage and validation

Technical Details

  • Compatible with Odoo 18.0 Community & Enterprise
  • Main models: gestio.equipo, gestio.empleat, gestio.prestec
  • Easy to extend with Inventory, Helpdesk or HR modules
  • Clean and modular code following Odoo guidelines

Installation Instructions

  1. Copy the folder gestio_equips_empleats into your addons directory
  2. Restart your Odoo server
  3. Activate Developer Mode
  4. Search for Gestió d'equips i empleats in Apps and click "Install"

Ideal For

  • IT Departments managing multiple devices
  • HR teams keeping control over equipment usage
  • Companies with loan/return policies for remote workers
  • Schools, tech firms, NGOs
